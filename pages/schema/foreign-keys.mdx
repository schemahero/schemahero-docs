# Foreign Keys

Foreign keys enforce referential integrity between tables.

**Note:** Cassandra does not support foreign keys.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `columns` | array | Columns in this table (required) |
| `references.table` | string | Referenced table (required) |
| `references.columns` | array | Referenced columns (required) |
| `onDelete` | string | Delete behavior |
| `name` | string | Constraint name |

## Basic Foreign Key

## ON DELETE Actions

What happens when the referenced row is deleted:

```yaml
foreignKeys:
  - columns: [author_id]
    references:
      table: users
      columns: [id]
    onDelete: CASCADE
```

| Action | Description |
|--------|-------------|
| `CASCADE` | Delete rows that reference the deleted row |
| `SET NULL` | Set the foreign key column to NULL |
| `SET DEFAULT` | Set to default value |
| `RESTRICT` | Prevent deletion if referenced |
| `NO ACTION` | Same as RESTRICT (default) |

### Examples

```yaml
# Delete posts when author is deleted
foreignKeys:
  - columns: [author_id]
    references:
      table: users
      columns: [id]
    onDelete: CASCADE

# Keep posts, set author to NULL
foreignKeys:
  - columns: [author_id]
    references:
      table: users
      columns: [id]
    onDelete: SET NULL

# Prevent user deletion while posts exist
foreignKeys:
  - columns: [author_id]
    references:
      table: users
      columns: [id]
    onDelete: RESTRICT
```

## Composite Foreign Keys

Reference multi-column primary keys:

```yaml
foreignKeys:
  - columns: [tenant_id, order_id]
    references:
      table: orders
      columns: [tenant_id, id]
```

## Self-Referential

Table referencing itself (e.g., hierarchies):

```yaml
schema:
  postgres:
    primaryKey: [id]
    columns:
      - name: id
        type: serial
      - name: name
        type: varchar(100)
      - name: parent_id
        type: integer
    foreignKeys:
      - columns: [parent_id]
        references:
          table: categories
          columns: [id]
        onDelete: SET NULL
```

## Naming

SchemaHero auto-generates constraint names. Specify a custom name:

```yaml
foreignKeys:
  - columns: [author_id]
    references:
      table: users
      columns: [id]
    name: fk_posts_author
```
