# Constraints

Constraints enforce rules on column values.

## NOT NULL

Prevent NULL values:

```yaml
columns:
  - name: email
    type: varchar(255)
    constraints:
      notNull: true
```

Generated SQL:
```sql
email varchar(255) NOT NULL
```

### Adding NOT NULL to Existing Column

When adding NOT NULL to a column that might have NULL values, you need a default:

```yaml
columns:
  - name: status
    type: varchar(20)
    default: "'pending'"
    constraints:
      notNull: true
```

Or backfill NULLs before applying:
```sql
UPDATE users SET status = 'pending' WHERE status IS NULL;
```

## UNIQUE

Ensure unique values:

```yaml
columns:
  - name: email
    type: varchar(255)
    constraints:
      unique: true
```

Generated SQL:
```sql
email varchar(255) UNIQUE
```

For multi-column unique constraints, use indexes:

```yaml
indexes:
  - columns: [tenant_id, email]
    name: idx_unique_tenant_email
    isUnique: true
```

## CHECK Constraints (PostgreSQL)

Validate values against an expression:

```yaml
columns:
  - name: age
    type: integer
    constraints:
      check: "age >= 0 AND age < 150"
```

```yaml
columns:
  - name: status
    type: varchar(20)
    constraints:
      check: "status IN ('pending', 'active', 'inactive')"
```

Generated SQL:
```sql
age integer CHECK (age >= 0 AND age < 150)
```

## Default vs Constraint

Defaults and constraints work together:

```yaml
columns:
  - name: role
    type: varchar(20)
    default: "'user'"          # Default value if not specified
    constraints:
      notNull: true            # Cannot be NULL
      check: "role IN ('user', 'admin', 'moderator')"  # Valid values
```

## Removing Constraints

Remove the constraint from your YAML:

```yaml
# Before
columns:
  - name: phone
    type: varchar(20)
    constraints:
      notNull: true

# After
columns:
  - name: phone
    type: varchar(20)
```

Generated SQL:
```sql
ALTER TABLE users ALTER COLUMN phone DROP NOT NULL;
```

## Constraint Names

PostgreSQL and MySQL auto-generate constraint names. For explicit names, some constraints support it:

```yaml
indexes:
  - columns: [email]
    name: users_email_unique    # Explicit name
    isUnique: true
```

## Database Differences

### PostgreSQL

Full constraint support:
- NOT NULL
- UNIQUE
- CHECK
- FOREIGN KEY (via foreignKeys)
- PRIMARY KEY (via primaryKey)

### MySQL

- NOT NULL
- UNIQUE
- FOREIGN KEY (via foreignKeys)
- PRIMARY KEY (via primaryKey)
- CHECK (MySQL 8.0.16+, but often not enforced)

### SQLite

- NOT NULL
- UNIQUE
- PRIMARY KEY
- FOREIGN KEY (must enable with `PRAGMA foreign_keys = ON`)
- CHECK
