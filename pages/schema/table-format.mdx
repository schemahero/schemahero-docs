# Table Format

SchemaHero tables are defined in YAML. The structure varies by database type.

## Basic Structure

```yaml
apiVersion: schemas.schemahero.io/v1alpha4
kind: Table
metadata:
  name: my-table
spec:
  database: my-database
  name: actual_table_name
  schema:
    postgres:    # Database-specific schema
      # ...
```

## Metadata

```yaml
metadata:
  name: users           # Identifier (not the table name)
  namespace: default    # Kubernetes namespace (operator only)
```

## Spec Fields

| Field | Required | Description |
|-------|----------|-------------|
| `database` | No* | Database resource name (operator only) |
| `name` | Yes | Actual table name in the database |
| `schema` | Yes | Database-specific schema definition |
| `requires` | No | Tables that must exist first |
| `seedData` | No | Initial data to insert |

## Database Schemas

Select your database:

<Tabs items={['PostgreSQL', 'MySQL', 'SQLite', 'Cassandra', 'CockroachDB']}>
  <Tab>
    ```yaml
    schema:
      postgres:
        schema: public              # PostgreSQL schema (optional)
        primaryKey: [id]
        columns:
          - name: id
            type: serial
            constraints:
              notNull: true
            attributes:
              autoIncrement: true
            default: "nextval('seq')"
        indexes:
          - columns: [email]
            name: idx_email
            isUnique: true
            type: btree             # btree, hash, gin, gist
        foreignKeys:
          - columns: [team_id]
            references:
              table: teams
              columns: [id]
            onDelete: CASCADE
            name: fk_team
        triggers:
          - name: updated_at_trigger
            events: [UPDATE]
            execute:
              type: Function
              name: update_timestamp
    ```
    
    **PostgreSQL-specific fields:**
    - `schema` — PostgreSQL schema (default: public)
    - `triggers` — Trigger definitions
    - Index `type` — btree, hash, gin, gist
  </Tab>
  <Tab>
    ```yaml
    schema:
      mysql:
        defaultCharset: utf8mb4
        collation: utf8mb4_unicode_ci
        primaryKey: [id]
        columns:
          - name: id
            type: int
            constraints:
              notNull: true
            attributes:
              autoIncrement: true
          - name: email
            type: varchar(255)
            charset: utf8mb4
            collation: utf8mb4_unicode_ci
        indexes:
          - columns: [email]
            name: idx_email
            isUnique: true
            type: btree             # btree, fulltext
        foreignKeys:
          - columns: [team_id]
            references:
              table: teams
              columns: [id]
            onDelete: CASCADE
    ```
    
    **MySQL-specific fields:**
    - `defaultCharset` — Table default charset
    - `collation` — Table collation
    - Column `charset` / `collation` — Per-column override
    - Index `type` — btree, fulltext
  </Tab>
  <Tab>
    ```yaml
    schema:
      sqlite:
        strict: true               # SQLite strict mode
        primaryKey: [id]
        columns:
          - name: id
            type: integer
            constraints:
              notNull: true
            attributes:
              autoIncrement: true
        indexes:
          - columns: [email]
            name: idx_email
            isUnique: true
        foreignKeys:
          - columns: [team_id]
            references:
              table: teams
              columns: [id]
            onDelete: CASCADE
    ```
    
    **SQLite-specific fields:**
    - `strict` — Enable STRICT mode (SQLite 3.37+)
    
    **Note:** Enable foreign keys in your app:
    ```sql
    PRAGMA foreign_keys = ON;
    ```
  </Tab>
  <Tab>
    ```yaml
    schema:
      cassandra:
        primaryKey:
          - [partition_key]        # Partition key(s)
          - [clustering_col]       # Clustering column(s)
        clusteringOrder:
          column: clustering_col
          isDescending: true
        columns:
          - name: partition_key
            type: uuid
          - name: clustering_col
            type: timestamp
          - name: data
            type: text
            isStatic: true
        properties:
          defaultTTL: 86400
          gcGraceSeconds: 864000
          bloomFilterFPChance: "0.01"
          comment: "My table"
          compaction:
            class: LeveledCompactionStrategy
          compression:
            sstable_compression: LZ4Compressor
    ```
    
    **Cassandra-specific fields:**
    - `primaryKey` — Nested array: [[partition], [clustering]]
    - `clusteringOrder` — Sort order for clustering columns
    - `isStatic` — Static column marker
    - `properties` — Table properties (TTL, compaction, etc.)
  </Tab>

## Complete Example

    ```yaml

    kind: Table
    metadata:
      name: users
    spec:
      database: myapp
      name: users
      schema:
        postgres:
          primaryKey: [id]
          columns:
            - name: id
              type: uuid
              default: gen_random_uuid()
            - name: email
              type: varchar(255)
              constraints:
                notNull: true
            - name: team_id
              type: uuid
            - name: created_at
              type: timestamp
              default: now()
          indexes:
            - columns: [email]
              name: idx_users_email
              isUnique: true
          foreignKeys:
            - columns: [team_id]
              references:
                table: teams
                columns: [id]
              onDelete: SET NULL
    ```
