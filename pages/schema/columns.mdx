# Columns

Column definitions vary slightly by database type.

## Common Types

<Tabs items={['PostgreSQL', 'MySQL', 'SQLite', 'Cassandra']}>

    - name: id

**Important:** String defaults need nested quotes: `default: "'value'"` not `default: "value"`

## Constraints

```yaml
columns:
  - name: email
    type: varchar(255)
    constraints:
      notNull: true
```

The only column-level constraint is `notNull`. For unique constraints, use indexes:

```yaml
indexes:
  - columns: [email]
    name: idx_email_unique
    isUnique: true
```

## Auto-Increment

<Tabs items={['PostgreSQL', 'MySQL', 'SQLite']}>
  <Tab>
    Use `serial` or `bigserial` types:
    ```yaml
    - name: id
      type: serial
    
    - name: id
      type: bigserial
    ```
  </Tab>
  <Tab>
    Use the `autoIncrement` attribute:
    ```yaml
    - name: id
      type: int
      attributes:
        autoIncrement: true
    ```
  </Tab>
  <Tab>
    Use `integer` primary key with `autoIncrement`:
    ```yaml
    primaryKey: [id]
    columns:
      - name: id
        type: integer
        attributes:
          autoIncrement: true
    ```
    
    **Note:** SQLite AUTOINCREMENT only works on INTEGER PRIMARY KEY.
  </Tab>
</Tabs>
