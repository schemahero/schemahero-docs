# 🦸 SchemaHero

## Declarative Database Schema Migrations for Kubernetes

SchemaHero is a Kubernetes operator that enables you to define database schemas declaratively.
Write your desired schema state, and SchemaHero automatically generates and applies the migrations.

## How It Works

```yaml filename="users-table.yaml"
apiVersion: schemas.schemahero.io/v1alpha4
kind: Table
metadata:
  name: users
spec:
  database: my-database
  name: users
  schema:
    postgres:
      primaryKey: [id]
      columns:
        - name: id
          type: uuid
          default: uuid_generate_v4()
        - name: email
          type: varchar(255)
          constraints:
            notNull: true
        - name: created_at
          type: timestamp
          default: now()
```

Apply this to your cluster, and SchemaHero will:

1. **Compare** your desired schema with the current database state
2. **Generate** the necessary `ALTER TABLE` or `CREATE TABLE` statements
3. **Create** a Migration resource for review (or auto-apply with `immediateDeploy`)

## Quick Start

```bash
# Install SchemaHero
kubectl schemahero install

# Connect to your database
kubectl apply -f database.yaml

# Define your tables
kubectl apply -f tables/

# Review pending migrations
kubectl schemahero get migrations

# Approve a migration
kubectl schemahero approve migration-name
```
