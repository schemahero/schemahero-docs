# RQLite Versions

SchemaHero is tested against the following RQLite versions:

| RQLite Version | Minimum SchemaHero Version |
|---------------|---------------------------|
| 9.x | 0.24.0 |
| 8.x | 0.24.0 |

RQLite uses SQLite as its storage engine, so SchemaHero's SQLite compatibility applies.
