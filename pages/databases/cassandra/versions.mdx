# Cassandra Versions

SchemaHero is tested against the following Cassandra versions:

| Cassandra Version | Minimum SchemaHero Version |
|------------------|---------------------------|
| 5.0.x | 0.24.0 |
| 4.1.x | 0.24.0 |
| 4.0.x | 0.24.0 |

Older versions of Cassandra (3.11) may work but are no longer actively tested.
