# CockroachDB Versions

SchemaHero is tested against the following CockroachDB versions:

| CockroachDB Version | Minimum SchemaHero Version |
|--------------------|---------------------------|
| v25.x | 0.24.0 |
| v24.x | 0.24.0 |

Older versions of CockroachDB (v19-v23) may work but are no longer actively tested.
