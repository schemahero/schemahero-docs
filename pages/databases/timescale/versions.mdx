# TimescaleDB Versions

SchemaHero is tested against the following TimescaleDB versions:

| TimescaleDB Version | PostgreSQL Version | Minimum SchemaHero Version |
|--------------------|-------------------|---------------------------|
| 2.25.x | PostgreSQL 17 | 0.24.0 |

TimescaleDB 2.x versions are broadly compatible with SchemaHero.
