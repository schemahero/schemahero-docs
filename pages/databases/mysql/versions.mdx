# MySQL Versions

SchemaHero is tested against the following MySQL versions:

| MySQL Version | Minimum SchemaHero Version |
|--------------|---------------------------|
| 9.x | 0.24.0 |
| 8.4.x | 0.24.0 |
| 8.0.x | 0.24.0 |

Older versions of MySQL may work but are no longer actively tested.
