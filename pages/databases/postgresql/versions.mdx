# PostgreSQL Versions

SchemaHero is tested against the following PostgreSQL versions:

| PostgreSQL Version | Minimum SchemaHero Version |
|-------------------|---------------------------|
| 18.x | 0.24.0 |
| 17.x | 0.24.0 |
| 16.x | 0.24.0 |
| 15.x | 0.24.0 |
| 14.x | 0.24.0 |

Older versions of PostgreSQL (9.5 through 13) may work but are no longer actively tested.
