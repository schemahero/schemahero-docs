# v0.23.1

Released on February 4, 2026

## Bug Fixes

- **Fix version string in release binaries** - Fixed an issue where darwin binaries incorrectly reported `v0.23.0-alpha.7` instead of the correct version. The Makefile now properly passes the VERSION variable to sub-makes during the release build process. ([#1300](https://github.com/schemahero/schemahero/pull/1300))

## New Features

- **Batch window support for multi-table deployments** - Added `batchWindow` field to the Database CRD, allowing efficient batching of table reconciliations. When multiple tables are created or updated simultaneously, SchemaHero now waits for the batch window duration before processing, reducing database connection overhead. ([#1297](https://github.com/schemahero/schemahero/pull/1297))

- **Improved logging for in-sync tables** - Added info-level logging when a table is already in sync with the database, providing better visibility during reconciliation. ([#1288](https://github.com/schemahero/schemahero/pull/1288))
