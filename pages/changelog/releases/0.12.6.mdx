# 0.12.6

**Released:** 2021-10-26

## Changes

- Implement updating controller pods
- MySQL index name cannot be longer than 64 chars
- Create tables with indexes if they are specified
- create an adopters file, link to it from readme, and add Replicated as an adopter
- Bump github.com/go-sql-driver/mysql from 1.5.0 to 1.6.0
- Bump github.com/aws/aws-sdk-go-v2/config from 1.5.0 to 1.8.2
- Bump github.com/aws/aws-sdk-go-v2/service/ssm from 1.8.0 to 1.11.0
- Bump github.com/onsi/gomega from 1.14.0 to 1.16.0
- Bump sigs.k8s.io/controller-runtime from 0.9.5 to 0.10.2
- Bump github.com/aws/aws-sdk-go-v2/credentials from 1.3.2 to 1.4.2
- Bump github.com/spf13/viper from 1.8.1 to 1.9.0
- Bump k8s.io/cli-runtime from 0.21.3 to 0.22.2
- Bump k8s.io/apiextensions-apiserver from 0.21.3 to 0.22.2
